# Финансовый терминал

Веб-терминал для отслеживания котировок, управления watchlist и портфелем.
Аналог https://github.com/Serstakt/finance-terminal без раздела «Финансовые показатели»
и без использования Yahoo Finance (котировки: MOEX ISS API + CoinGecko).

## Стек
- **Backend:** Python 3.11+ / FastAPI
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Database:** SQLite (SQLAlchemy)

## Функционал
- **Главная** — обзор рынка (виджет TradingView, виджет Investing.com), быстрые действия
- **Watchlist** — несколько списков наблюдения (хранение в БД), разделы, drag&drop,
  сортировка по колонкам, флажки избранного, ценовые алерты (звук + уведомления),
  график свечей по выбранному тикеру (KLineChart: Мосбиржа ISS/Algopack и Binance,
  таймфреймы 1ч/1д/1н/1М, типы графика, индикаторы с редактором настроек
  «Входные данные/Стиль» как в TradingView, профиль объёма сбоку, сравнение
  нескольких инструментов на одной шкале, разметка с сохранением по тикеру),
  новости Telegram (@newssmartlab),
  автообновление цен, экспорт/импорт настроек
- **FUTOI** — открытые позиции по фьючерсам в разрезе физлиц и юрлиц
  (MOEX ISS+ FUTOI): дневной график по корню инструмента (MX — все серии
  на индекс МосБиржи), режимы «лонги и шорты», «чистая позиция», «доля
  шортов/лонгов», «изменение за день», OI; периоды 1М/3М/6М/1Г/Всё.
  С токеном `MOEX_API_TOKEN` данные без задержки, на бесплатном тарифе
  ISS+ — с задержкой 14 дней (показывается в разделе)
- **Отчетность** — финансовые показатели компаний из watchlist (кроме crypto).
  Слева — бумаги watchlist, справа — таблица в духе smart-lab: выручка, EBITDA,
  операционная и чистая прибыль, денежный поток, CAPEX/FCF, активы, капитал,
  долг, чистый долг, рентабельность. Колонки — периоды из загруженных PDF/ZIP:
  кварталы, полугодия, 9 месяцев, годы (фильтры + режим «Изм. %»). Кнопка
  «Добавить колонку» загружает документ по выбранной бумаге: бэкенд находит
  таблицы «Отчет о прибылях и убытках», «… о движении денежных средств» и
  «Бухгалтерский баланс», распознаёт колонки по геометрии чисел, отступы,
  жирные итоги и отрицательные значения в скобках, приводит статьи к единому
  набору показателей и склеивает периоды (ОПиУ/ДДС + баланс по дате). Всё
  хранится в SQLite; исходные распознанные таблицы доступны у каждого
  документа; страницы-сканы распознаются встроенным OCR Windows (русский
  языковой пакет, только Windows), такие таблицы помечены «OCR»
- **Портфель** — позиции (тикер/кол-во/средняя цена/сектор), расчёт P&L,
  сводная статистика, круговая диаграмма (по тикерам/секторам), столбчатая диаграмма P&L

## Источники данных
| Префикс | Источник |
|---------|----------|
| `MOEX:` | Мосбиржа ISS API (акции, облигации, индексы, валюты) |
| `BINANCE:` | CoinGecko (криптопара, например BTCUSDT) |
| без префикса | автоопределение: крипто → BINANCE, иначе → MOEX |
| FUTOI | MOEX ISS+ `/iss/analyticalproducts/futoi` (открытые позиции физ./юр. лиц) |
| Отчетность | Загружаемые PDF/ZIP с отчётностью — парсинг на бэкенде (PyMuPDF), без внешних запросов |

Yahoo Finance **не используется**.

## Установка и запуск
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r backend/requirements.txt
python -m backend.main          # или: uvicorn backend.main:app --reload
```

Откройте http://localhost:8000
